## 💼 Proyectos destacados

### 🗺️ Optimización de rutas

Aplicación web para generar rutas optimizadas para mercaderistas, considerando orden de visita, distancia, tiempo de traslado y otros indicadores.

**Tecnologías:** .NET / PHP, React / JavaScript, Leaflet, OSRM.

### 📊 Integración con Power BI

Plataforma web para gestionar la carga y actualización de reportes `.pbix` mediante integración con Power BI.

**Tecnologías:** PHP, JavaScript, Power BI API, Power BI Pro.

### 🏢 Plataforma empresarial

Desarrollo de una plataforma corporativa con gestión de usuarios, roles, permisos, cuentas de clientes, pantallas personalizadas y reportes.

**Tecnologías:** PHP, JavaScript, Bootstrap, MySQL.

### ⚙️ Automatización y CI/CD

Implementación de procesos automáticos mediante Cron Jobs, WebJobs y GitHub Actions para envío de información, ejecución de procesos y despliegues automáticos.

**Tecnologías:** GitHub Actions, Azure, PHP, CI/CD.

### 📱 Aplicaciones móviles

Mantenimiento y desarrollo de aplicaciones Android para gestión de puntos de venta, rastreo, evaluaciones y generación de reportes.

**Tecnologías:** Java, Android Studio, Firebase, SQLite, MySQL, REST APIs.
